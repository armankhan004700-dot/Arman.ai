Installation & Setup Guide

1

Download the Installer

Click the download button above for your platform. The installer will begin downloading automatically.

2

Run the Installer

Android: Tap the APK file in your Downloads folder.

3

Allow necessary permissions for file access, storage, and microphone (for voice commands).

Visit console.x.ai and get your free API key. You get $25 free credits monthly!

Open Arman.AI, go to Settings, and paste your Grok API key. Configure Gmail and Telegram (optional).

Start Using!

Use voice commands or text chat. Type "help" to see all available commands and features.
